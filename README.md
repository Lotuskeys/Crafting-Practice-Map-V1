# How to put the map on your Ranked instance

## Step-by-step

1. Unzip the file.
2. Locate your Minecraft instance folder by right clicking the instance in Prism or MultiMC.
3. Go to your `.minecraft` folder.
4. Open the `saves` folder.
5. Put the unzipped map folder into the `saves` folder.
6. Check your worlds in Minecraft.

## Having issues?

If you have any issues, ask in **rankedcord public help**.
